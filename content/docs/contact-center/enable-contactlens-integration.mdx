# Contact Lens の連携を有効にする

このページは、ネスト構造（`/docs/contact-center/enable-contactlens-integration`）の
ドキュメントが通常 HTML として表示され、同じパスに `.md` を付けると raw Markdown が
返ることを確認するためのサンプルです。

## 概要

Contact Lens を使うと、通話やチャットの分析（感情分析・要約・キーワード検出など）を
コンタクトセンターのワークフローに組み込めます。

## 有効化の手順

1. 管理コンソールにサインインします。
2. 対象のフローを開きます。
3. 「分析と最適化」ブロックを追加し、Contact Lens を有効化します。
4. フローを保存して公開します。
