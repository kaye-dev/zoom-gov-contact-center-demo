# 庁舎案内

未来市役所本庁舎のフロア構成と各種窓口をご案内します。ご来庁の際の参考にしてください。

## 所在地・開庁時間

| 項目     | 内容                               |
| -------- | ---------------------------------- |
| 住所     | 〒100-0000 未来市未来 1-1-1        |
| 開庁時間 | 平日 8:30 〜 17:15                 |
| 休庁日   | 土曜・日曜・祝日・年末年始         |
| 代表電話 | (03)1234-5678                      |

## フロア案内

- **1 階**: 総合案内、市民課（住民票・戸籍）、税務課
- **2 階**: 保険年金課、福祉課、子育て支援課
- **3 階**: 都市計画課、建築指導課、環境課
- **4 階**: 会議室、相談コーナー

## アクセス

- 電車: 未来駅 中央口から徒歩 5 分
- バス: 「市役所前」バス停すぐ
- お車: 来庁者用駐車場をご利用ください（30 分無料）

## バリアフリー

各階に多目的トイレ・エレベーターを設置しています。車いすの貸し出しは 1 階総合案内で
承ります。

ご不明な点は [ご意見・ご要望](/docs/feedback) よりお問い合わせください。
