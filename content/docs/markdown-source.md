# .md ソースの例

このページはソースが `.md` 拡張子のドキュメントです。`next.config.ts` の
`createMDX({ extension: /\.(md|mdx)$/ })` 設定により、`.md` も MDX として
コンパイルされ HTML として表示されます。

## 確認ポイント

- 通常表示: [`/docs/markdown-source`](/docs/markdown-source)
- Markdown 版: [`/docs/markdown-source.md`](/docs/markdown-source.md)

`.md` 版にアクセスすると、このファイルの raw テキストがそのまま返ります。
