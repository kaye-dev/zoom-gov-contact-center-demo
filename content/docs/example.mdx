# ドキュメントの例

このページは、Markdown/MDX を唯一のソース（single source of truth）として、
通常アクセスでは HTML、`.md` を付けてアクセスすると raw Markdown を返す仕組みのデモです。

## 使い方

- 通常表示: [`/docs/example`](/docs/example) または [`/docs/example.html`](/docs/example.html)
- Markdown 版: [`/docs/example.md`](/docs/example.md)

`.md` でアクセスすると、レイアウトを含まない素の Markdown テキストが
`Content-Type: text/markdown; charset=utf-8` で返ります。

## GitHub Flavored Markdown

`remark-gfm` を有効にしているため、表やタスクリストも使えます。

| 項目         | 通常ページ           | Markdown 版           |
| ------------ | -------------------- | --------------------- |
| パス         | `/docs/example`      | `/docs/example.md`    |
| Content-Type | `text/html`          | `text/markdown`       |
| レイアウト   | あり                 | なし（raw のみ）      |

- [x] MDX をソースにする
- [x] 通常ページは HTML 表示
- [x] `.md` は raw Markdown を返す

> 存在しないパス（例: `/docs/missing`）は 404 を返します。
