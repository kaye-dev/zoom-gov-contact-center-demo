# Zoom Contact Centerフロー作成スキルの使い方

`$zoom-contact-center-flow` は、Zoom Contact Centerのフローを自然言語の要望や既存のエクスポートJSONから設計・作成・変更し、配置と処理の整合性を確認するためのCodexスキルです。デモのシナリオをフローへ落とし込むときや、既存フローを運用しやすく整理するときに使います。

スキル名は `zoom-contact-center-flow` です。このリポジトリの [SKILL.md](../../.agents/skills/zoom-contact-center-flow/SKILL.md) と、その配下の補助CLI・参照資料を管理対象とします。

## 普段使う場面

| やりたいこと | 依頼する内容 | 主な確認点 |
| --- | --- | --- |
| 新しいデモフローを作る | 案内文、メニュー、分岐先、無入力・失敗時の動作を伝える | 要望とノード・出口・確認シナリオの対応 |
| 既存フローの動作を変える | エクスポートJSONと、変更する文言・条件・接続先を渡す | 指定箇所の変更と、維持する処理への影響 |
| 大きなフローを読みやすくする | JSONや画面例を渡し、カードが重ならない程度に余白を詰めるよう依頼する | 座標以外の処理を保ち、カードや接続線を追える配置にする |
| 合流が多い箇所を整理する | 読みにくい接続先を指定し、必要な箇所だけ分離するよう依頼する | 共通処理の保守性、複製元との同等性、残る合流や循環 |
| 変更済みJSONを確認する | 変更前後のJSONと期待する動作を渡す | 名前・ID・接続先・必須出口・到達性・指定シナリオ |

このスキルが扱うのはZCCフローの設計とファイル作成です。Webサイトの画面やAPIの実装は[通常の開発ワークフロー](codex-development-workflow.md)を使います。Queue・電話番号・Campaignの設定や発信を含むデモ構築では、[ZCCデモ設定手順](../knowledge-base/ZCC設定/01_Agentless_Dialer_光化学スモッグ注意報デモ.md)と組み合わせ、フロー作成部分にこのスキルを使います。

## 依頼例

このリポジトリを開いたCodexで、スキル名と目的を伝えます。最初からJSONの書き方や補助CLIを覚える必要はありません。

### 案内して終了するフローを新規作成する

```text
$zoom-contact-center-flow
音声フローを作成してください。
「受付を終了します。」と案内し、正常時もメディア送信失敗時も切断してください。
JSON・配置図・検証結果を納品してください。
```

### 案内文だけを変更する

```text
$zoom-contact-center-flow
添付のエクスポートJSONについて、SM_Noticeの案内を
「またのご利用をお待ちしています。」へ変更してください。
分岐と接続先は維持してください。
```

### 余白を詰め、必要な終端だけ分離する

```text
$zoom-contact-center-flow
添付のフローを、カードが重ならず接続を追える配置にしてください。
共通の案内と転送処理は再利用し、見づらい切断終端だけ分離してください。
処理内容は維持してください。
```

既存変更ではスクリーンショットに加えてエクスポートJSONがあると、設定と接続を比較できます。新規作成でも、利用するチャネルやウィジェットの形式が未確認なら、必要な最小限のエクスポートを取得してから生成します。スクリーンショットだけで不明な設定値を補完することはありません。

## 依頼時に伝えること

対象チャネル、案内内容、入力・分岐、接続先、再試行、無入力・失敗時の動作、終了条件を、分かる範囲で伝えてください。既存変更では「変える箇所」と「維持する箇所」を添えます。スキルは動作を左右する不足事項だけを確認し、命名や配置は依頼に沿って進めます。

既定の配置方針は、共通処理を再利用し、必要な箇所だけ分離することです。全ての合流を分離したい場合は明示してください。循環や変数参照など、単純な複製で処理の意味が変わる部分は、保持理由や代案を確認します。

## 受け取るものと確認範囲

通常は元ファイルを保持し、新しい出力先に次の4ファイルを作成します。

| ファイル | 用途 |
| --- | --- |
| `flow.json` | 生成・変更したZoom用JSON |
| `flow.svg` | 同じノード・接続・座標に基づく配置図 |
| `verification.json` | 構造・配置・シナリオの検証結果、複製元との対応、未確認事項 |
| `summary.md` | 要件への対応、変更点、不足している外部設定、取り込み時の案内 |

ローカル検証済みとZoomへの取り込み確認済みは別の状態です。SVGの線描画もZoom画面と一致する保証はありません。ZoomはJSONの手編集をサポート対象としていないため、取り込みを依頼した際に対象環境で確認します。[Zoom公式インポート仕様](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0058787)

設計対象は音声・ビデオ・メッセージング・メール・Work Itemですが、同梱の実形式プロファイルは音声の一部ウィジェットに限られます。他チャネルや未確認ウィジェットは、実エクスポートと確認済み仕様を追加して扱います。キューやアセットのIDを推測せず、仮値が残るJSONを取り込み用の完成品として渡しません。詳細は[対応範囲と出典](../../.agents/skills/zoom-contact-center-flow/references/sources.md)を参照してください。

標準の完了地点はファイルの納品です。Zoomへの取り込み・公開、アカウント設定の変更、発信は、実際に依頼した範囲で扱います。補助CLIを直接使う場合や形式を拡張する場合は、[CLIの手順](../../.agents/skills/zoom-contact-center-flow/references/cli.md)を参照してください。
