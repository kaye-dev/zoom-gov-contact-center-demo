# チャット：粗大ごみの出し方・収集申込み

## 検証言語

- 한국어 / `ko`
- 利用者の送信文に対し、AIの案内、確認、転送前の同意確認と要約が韓国語で統一され、日本語など別の言語が混在しないことを確認する。

## 狙い

品目・寸法・数量を含む自然な質問から、AIが粗大ごみ収集の標準手順を案内する。運び出し支援のように未来市で個別判断が必要な相談は、対象可否を推測せず有人担当へ引き継ぐ。

## 答えられる範囲

- 家庭から出る大きな家具や耐久消費財などを、品目、材質、大きさで粗大ごみとして判断する一般的な考え方
- 品目、寸法、数量、排出場所を確認すること
- 収集には事前申込みが必要で、収集日と手数料は申込み時に確認すること
- 案内された金額分の処理券を購入し、必要事項を記入して見やすい場所へ貼ること
- 指定された日時と場所へ排出するまでの標準的な流れ

## 意図的に答えられない範囲

- 品目別の正確な手数料
- 収集日の空き状況、予約の確定、受付情報の発行
- 室内からの運び出し支援について、未来市で適用される条件や個別の対象判定

AIは具体値や手続き完了を作り出さない。個別判断が必要な場合は、利用者の同意を得て有人転送を一度だけ実行する。

## 事前確認

- 更新済みの粗大ごみFAQがAIへ割り当てられていること
- 「転送無し」は標準手順、「転送あり」は運び出し支援の個別相談の新しいチャットで開始すること
- 有人担当が応答でき、転送前の同意と引継ぎ内容を確認できること
- AIの回答を固定文言で判定せず、各進行表に記載した意味と動作が含まれるかを確認すること
