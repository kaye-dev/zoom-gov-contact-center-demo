# 音声 : マイナポータルへのログイン、電子証明書のエラー

AI による原因切り分けと、有人窓口へのスムーズな引き継ぎ

## よくある発生場面

1. 数字4桁の暗証番号を間違えた

マイナポータルへのログインには「利用者証明用電子証明書」の数字4桁の暗証番号を使用します。3回連続で間違えるとロックされ、ログインできなくなります。

2. 電子証明書の有効期限が切れた

カード本体が有効でも、カード内の電子証明書が期限切れになると、マイナポータルへログインできません。更新は住民票のある市区町村の窓口で行います。

3. 電子証明書の有効期限が近い

ログイン時に「利用者証明用の電子証明書を更新してください」といった案内が表示されます。

4. スマートフォンでカードを読み取れない

カードを当てる位置が違う、途中でカードを動かす、スマートフォンやブラウザが動作環境を満たしていない、といった場合に処理が止まることがあります。公式FAQでも、ログインできない場合は動作環境を満たしていない可能性が案内されています。

5. 電子証明書の更新直後

市区町村窓口で更新・再発行をした直後は、情報連携の都合で一時的にログインできない場合があります。

6. 電子申請時に署名用電子証明書でエラーが出た

ログインはできても、申請を送信する際に使う署名用電子証明書が期限切れだと、電子署名を付けられません。

## 参考

マイナンバー関連では、主にマイナンバーカードの申請・受け取り・更新・暗証番号についての問い合わせが多いです。

* マイナンバーカードの申請方法、申請状況
* カード受け取りの予約、受取場所、必要書類
* カードや電子証明書の有効期限・更新手続き
* 暗証番号を忘れた、暗証番号がロックされた
* 氏名・住所変更後のカード手続き
* カードを紛失・破損した場合の手続き
* マイナ保険証の利用登録や、利用できない場合の相談
* マイナポータルへのログイン、電子証明書のエラー
* 子どもや代理人による申請・受け取り
* 個人番号通知書や自分のマイナンバーの確認方法

特に窓口への案内が必要になりやすいのは、カードの受け取り、電子証明書の更新、暗証番号の再設定・ロック解除です。
電子証明書の更新は原則として市区町村窓口で行い、暗証番号のロック解除も窓口で対応できる場合があります。
