# 転送無し

```
AI：
お電話ありがとうございます。未来市AI総合案内サービスです。
本日はどのようなお問い合わせでしょうか。

利用者：
マイナポータルにログインできません。

AI：
マイナポータルへのログインについてですね。
状況を確認するため、いくつか質問します。

画面には、どのような表示が出ていますか。

利用者：
マイナンバーカードを読み取れませんと表示されます。

AI：
承知しました。
暗証番号のエラーではなく、スマートフォンでマイナンバーカードを読み取れない状況ですね。

まず、スマートフォンのケースやカバーを付けていますか。

利用者：
はい、付けています。

AI：
ケースの厚みや材質によって、カードを読み取りにくい場合があります。
お手数ですが、いったんケースを外してください。

利用者：
外しました。

AI：
ありがとうございます。
次に、マイナンバーカードを机の上に置き、スマートフォンの背面をカードに重ねてください。

読み取り位置は機種によって異なります。
スマートフォンの背面上部、中央付近、下部の順に、ゆっくり位置を変えてお試しください。

読み取りが完了するまで、スマートフォンとカードを動かさずにお待ちください。

利用者：
今、読み取り中と表示されました。

AI：
そのまま動かさずにお待ちください。

利用者：
ログインできました。

AI：
ログインできたとのこと、承知しました。
今回の原因は、スマートフォンのケース、またはカードを当てる位置だった可能性があります。

今後も同じ事象が発生した場合は、次の順番でお試しください。

スマートフォンのケースを外す。
カードを机の上に置く。
スマートフォンの背面をカードに密着させる。
読み取りが完了するまで動かさない。

ほかにマイナポータルについて確認したいことはありますか。

利用者：
ありません。

AI：
承知しました。
本日のご案内は以上です。お電話ありがとうございました。
```
