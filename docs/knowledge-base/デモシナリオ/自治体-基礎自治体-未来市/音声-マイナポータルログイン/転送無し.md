# 転送無し

## 進行

| 段階 | デモ担当者 | 確認するAI動作 | 次へ進む条件 |
| --- | --- | --- | --- |
| 1（必須） | 「iPhoneでマイナンバーカードを読み取れず、マイナポータルにログインできません。スマートフォンのケースを付けたままですが、関係ありますか？」と話す | カード読取エラーとして状況を捉え、ケースが読み取りを妨げる場合があるため、外して試すという意味の案内をする | ケースを外し、カードを当てる位置の確認へ進める |
| 2（必須） | 「ケースを外しました。カードはiPhoneのどこに当てればよいですか？」と話す | マイナンバーカードの中心をiPhoneの上部へ押し当てるという意味の案内をする | カードを当てた後の操作を確認できる |
| 3（必須） | 「上部に当てたあとは、読み取りが終わるまでカードとiPhoneを動かさず待てばよいですか？」と話す | カードとiPhoneの位置をずらさず、動かさずにしばらく待つという意味の案内をする | ここで終了する場合は、3ターンの自己解決として完了する |
| 4（任意） | 「ログインに使う暗証番号は、数字4桁のもので合っていますか？」と話す | ログインには利用者証明用電子証明書の数字4桁の暗証番号を使い、暗証番号そのものは電話で伝えないという意味の案内をする | 時間に余裕があれば、電子証明書の期限を確認する |
| 5（任意） | 「電子証明書の期限が切れている場合も、マイナポータルにはログインできませんか？」と話す | 電子証明書の有効期限が切れるとログインできず、更新は住民票のある市区町村の窓口で手続きするという一般的な案内をする | 有人転送せず、5ターンの案内として完了する |

3ターン目で終了してよい。デモ時間に余裕がある場合だけ4〜5ターン目へ進む。

回答の語順や言い回し、1回の回答に含まれる情報量は毎回一致しなくてよい。AIが後続の論点を先に案内した場合も、確認質問として会話を続けられる。個人番号や暗証番号そのものを尋ねず、有人転送せずに上記の意味を確認できれば成功とする。
