# 音声：マイナポータルログイン

## 検証言語

- English / `en-US`
- 利用者の発話に対し、AIの案内、確認、転送前の同意確認と要約が英語で統一され、日本語など別の言語が混在しないことを確認する。

## 狙い

マイナポータルへログインできない状況をAIが切り分け、ナレッジで案内できるカード読取エラーは自己解決へ導き、未来市での個別確認が必要な暗証番号ロックは有人担当へ安全に引き継ぐ。

## 答えられる範囲

- ログインに使う利用者証明用電子証明書の暗証番号は数字4桁であること
- スマートフォンのケースを外し、端末に応じた読取位置へカードを当て、読取完了まで動かさないこと
- 数字4桁の暗証番号を3回連続で誤入力するとロックされること
- 電子証明書の有効期限と市区町村窓口での更新に関する一般的な案内
- 個人番号や暗証番号そのものを聞かずに行う安全な問い合わせ案内

## 意図的に答えられない範囲

- 未来市で暗証番号ロックを解除するときの必要な持ち物
- コンビニエンスストアで初期化・再設定できる具体的な利用条件
- 未来市の窓口で当日中に対応できるかどうか

AIはこれらを推測せず、個人番号や暗証番号を尋ねない。利用者の同意を得てから、有人転送を一度だけ実行する。

## 事前確認

- 更新済みのマイナンバーFAQがAIへ割り当てられていること
- 「転送無し」はカード読取エラー、「転送あり」は暗証番号ロックの新しい会話で開始すること
- 有人担当が応答でき、転送前の同意と引継ぎ内容を確認できること
- AIの回答を固定文言で判定せず、各進行表に記載した意味と動作が含まれるかを確認すること
