# 日本郵政グループ：デモシナリオ

ZVAとの会話を進める担当者向けの台本です。AIの返答や回答内容は台本化せず、利用者が何を相談し、どのように話を広げるかを記載しています。

- [音声シナリオ](音声.md)：短い発話を一つずつ伝える進行。
- [チャットシナリオ](チャット.md)：状況をまとめて入力し、必要な点を追加質問する進行。

## 使い方

- 各シナリオは新しい会話で開始します。短時間の場合は、各チャネルのシナリオ1だけを使用します。
- 番号順に進めますが、AIが先に説明した事項は飛ばしてください。追質問はすべて行う必要はありません。
- AIから確認質問があった場合は、その質問に答えてから次へ進みます。台本にない口座・契約条件を、その場で事実として作り足さないでください。
- 一般的な案内に戻す場合は「個別の口座や契約の確認ではなく、一般的な手続き方法を知りたいです」と伝えます。
- 案内を受けた時点で終了できます。実際の申込み、住所変更、保険金請求を完了させるシナリオではありません。
- 氏名、住所、口座番号、暗証番号、保険証券番号、病歴などの実情報は入力・発話しません。

## 使用する環境

対象は[日本郵政グループのZVA](https://zoom.us/ai-studio/virtual-agent/unified/2qr9K1BGT0yq6drS7wZ7XQ)です。2026年9月21日の調整では、ゆうちょ銀行の再構築KBに住所変更FAQ 2件を補完として関連付け、音声・チャット双方の検索ガイダンスを公開しています。

実施前に、使用する音声の接続先・チャットの入口がこのエージェントにつながることを確認してください。新規チャットでは住所変更の質問と言い換え、電話・郵送の確認、28kg・160cmの荷物の質問を確認済みです。本書の全追質問、音声の実通話、有人転送、AI Expert Assistを通した一連の動作は未検証です。

有人対応を含める場合は、各ファイル末尾の任意パートを使用します。担当者の待機、各チャネルの転送先、ZCC側の受信を事前に確認してください。AI Expert Assistを併せて見せる場合は、対象ナレッジへの関連付けも別途確認します。設定済みの転送先を、日本郵政グループ各社の実際の窓口として紹介しないでください。
