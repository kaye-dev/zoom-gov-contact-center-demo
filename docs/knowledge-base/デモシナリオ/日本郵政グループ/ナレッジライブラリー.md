# 日本郵政グループ：ナレッジライブラリーの作成手順

公開Webページを取得して、日本郵政グループ向けのZVAに関連付ける手順です。表示名は管理用の例で、既存のエージェントID・KB ID・管理画面URLを引き継ぐ必要はありません。日本郵政から提供を受けた内部資料は使用しません。

## 1. 作成するKB

以下の6つを個別に作成します。銀行の住所変更FAQは、広いFAQ集とは別の補完KBとして併用します。

| 表示名の例 | 取得元・開始URL | 役割 |
| --- | --- | --- |
| 日本郵便｜郵便・荷物FAQ | https://www.post.japanpost.jp/question/ | 郵便・荷物全般の問い合わせ |
| 日本郵便｜転居・転送サービス | https://www.post.japanpost.jp/service/receive/relocation/ | 転居届、転送、申込方法 |
| 日本郵便｜ゆうパック利用案内 | https://www.post.japanpost.jp/service/send/domestic/delivery/yu-pack/ | 荷物のサイズ・重量、利用方法 |
| ゆうちょ銀行｜手続き・サービスFAQ | https://faq.jp-bank.japanpost.jp/ | 銀行の手続き・サービス全般 |
| ゆうちょ銀行｜住所変更FAQ | 下記の2つの個別FAQ URL | 住所変更に必要な記事を検索で拾いやすくする補完 |
| かんぽ生命｜契約・保険手続きFAQ | https://faq.jp-life.japanpost.jp/ | 保険契約・請求書類などの一般案内 |

住所変更FAQには、URLアップロード方式で次の2件だけを指定します。

```text
https://faq.jp-bank.japanpost.jp/faq_detail.html?id=720
https://faq.jp-bank.japanpost.jp/faq_detail.html?id=724
```

日本郵便の旧URL `/service/tenkyo/` と `/service/you_pack/` は、2026年9月22日の公式サイト確認では上表のURLへ転送されました。新規作成では転送後のURLを使用します。以下のページ選択条件は新規作成向けの案であり、旧URLで作成したKBと同じ記事件数になることは保証しません。

## 2. 作成方法とページ選択

Zoom管理画面の「AI Studio」→「ナレッジライブラリ」から、ナレッジベースを作成し、ソースに「ウェブサイト」を選択します。画面の呼称は環境で異なる場合があります。Web同期にはサイトマップ・URLアップロード・リンク探索があり、リンク探索では開始URLと取得条件を指定します。[Zoom公式：Web同期によるKB作成](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0060767)

| KB | 新規作成で使用する方式 | ページ選択・条件 |
| --- | --- | --- |
| 郵便・荷物FAQ | リンク探索 | 開始URLと同じ `https://www.post.japanpost.jp/question/` 配下。個別の質問ページが含まれることを確認する。 |
| 転居・転送サービス | リンク探索 | `https://www.post.japanpost.jp/service/receive/relocation/` 配下。関連FAQは郵便・荷物FAQのKBでも取得する。 |
| ゆうパック利用案内 | リンク探索 | `https://www.post.japanpost.jp/service/send/domestic/delivery/yu-pack/` 配下。重量ゆうパックの説明が選択範囲にあるか確認し、配下外ならその公式ページを個別URLとして追加取得する。 |
| 銀行の手続き・サービスFAQ | リンク探索を明示選択 | 開始URLは `https://faq.jp-bank.japanpost.jp/`、条件は同じURLで始まるページ。既定の自動選択のまま確定しない。 |
| 銀行の住所変更FAQ | URLアップロード | FAQ 720・724の2件を指定。リンク探索で周辺ページまで増やさない。 |
| かんぽ生命FAQ | サイトマップ | 開始URLから提示されるページ一覧で `/faq/` 配下の個別FAQを選択する。トップページだけになっていないことを確認する。サイトマップを取得できない場合は、リンク探索でFAQ詳細を検出できるか確認する。 |

サイトマップ方式のかんぽ生命では、以前トップページだけが対象になっており、ページ選択を修正してFAQ本文を取得しました。別環境で候補が変わる場合も、一覧の件数だけでなく個別FAQが選ばれているかを見ます。

### 共通の抽出設定

- 「AIを活用してウェブコンテンツを抽出」がある場合は有効にします。これは2026年9月21日の作成時に使用した設定です。
- 表の抽出は「テーブル構造を保持する」を使用します。銀行の認証方法など、行と列の対応が必要な情報を確認してください。
- 画像・PDF・JavaScript・CSSセレクターの追加設定は、必要な本文が欠ける場合に対象ページを見て判断します。過去の環境から未確認のセレクターや設定値をコピーしません。
- 日本語の記事一覧を表示します。英語が選択されているだけで記事が見えない場合があります。
- 必要なら管理用グループ「日本郵政G」を作成します。グループ分けとは別に、ZVAへの関連付けを行います。

## 3. 同期完了と本文の確認

初回同期を開始し、完了するまで待ちます。以下の件数は2026年9月21日に観測した過去の値で、作成時の合格条件ではありません。公開サイトの更新、URLの重複、取得方式によって増減します。

| KB | 過去の収録件数 | 本文で確認する代表項目 |
| --- | ---: | --- |
| 郵便・荷物FAQ | 377 | 転居届の申込方法などの個別FAQ |
| 転居・転送サービス | 4 | 申込方法、転送期間、開始までの案内 |
| ゆうパック利用案内 | 50 | サイズ・重量の条件と重量ゆうパック |
| 銀行の手続き・サービスFAQ | 2,722 | 個別FAQの質問と回答本文 |
| 銀行の住所変更FAQ | 2 | FAQ 720・724の本文と認証方法の表 |
| かんぽ生命FAQ | 424 | [FAQ 332](https://faq.jp-life.japanpost.jp/faq/show/332?site_domain=default)の請求書類に関する本文 |

記事を開き、元URL・タイトル・回答本文を照合します。トップページ、カテゴリ一覧、ナビゲーションだけの取得を「回答可能」と扱わないでください。同一FAQのカテゴリ違い・ページ番号違いのURLがある場合は、同じ本文かを確認して重複を整理します。回答に必要な唯一の記事まで除外しないようにします。

### 銀行の住所変更KBを別に持つ理由

広いFAQ集で同期が成功し、FAQ 720・724の本文も収録されていても、ZVAが別の銀行手続きの記事を選ぶことがありました。住所変更の2件を別KBとして併用し、検索ガイダンスを調整した構成では、質問と言い換えの両方で必要な記事の参照を確認しました。

したがって、再作成時はまず6つのKBを併用します。本文が重なるという理由だけで補完KBを外さず、外す場合は新しい会話で検索と回答を再確認します。補完KBへの優先順位をシステムが保証する、という意味ではありません。

## 4. ZVAへの関連付けと検索ガイダンス

1. 実施環境で日本郵政グループ向けのZVAを作成し、「ナレッジ」の編集から上記6つを選択して保存します。
2. 音声・チャットの両方に、以下の検索方針を既存ガイダンスと矛盾しない形で設定します。回答本文をプロンプトに埋め込むのではなく、取得した記事を根拠に回答させます。
3. 挨拶・ガイダンスに「デモ用」「EBC」といった説明を含めず、設定を公開します。
4. 新しいプレビュー会話で確認します。作成前の会話や、前のKB構成での成功結果は再利用しません。

以下は、検証した検索方針を再設定するための文面です。エージェント全体のプロンプトや転送設定を置き換えるものではありません。

```text
サービスの事実は、割り当てられたナレッジの検索結果を根拠に回答します。
郵便・荷物・転居転送は日本郵便、貯金・銀行アプリはゆうちょ銀行、保険契約・請求はかんぽ生命の情報を参照し、各社の条件を混ぜません。
対象が不明な場合だけ、一つ確認質問をします。
複数の会社や手続きが含まれる質問は、会社と手続きごとに分けて検索します。
検索は原則1回、必要な根拠が不足する場合だけ追加で1回までにし、取得できたら回答します。
ゆうちょ銀行の住所変更では、引っ越しによる住所変更と、電話・郵送による住所変更のFAQを確認します。
氏名変更、法人、特定商品などの記事の条件を、一般の個人口座に当てはめません。
電話・郵送・Web・アプリの可否は、それぞれの根拠を確認します。
根拠がない点は確認できないと伝え、方法や条件を推測しません。
個別の口座・契約の照会や変更を実行したとは案内せず、暗証番号や口座番号などの実情報を求めません。
```

AI Expert Assistでも使用する場合は、ZCC側で利用する設定に同じKBを関連付け、担当者画面で検索できることを別途確認します。ZVAでの公開だけを、AI Expert Assistの設定完了や検証完了と扱わないでください。

## 5. 再作成後の確認

[音声](音声.md)・[チャット](チャット.md)のシナリオを使い、最低限、次の質問を新しい会話で試します。シナリオ本文にはAIの固定返答を置かず、ここでは設定担当者が参照記事と回答の整合性を確認します。

- 郵便局の転居届と、ゆうちょ銀行の住所変更を一度に質問する。
- 銀行の住所変更を電話・郵送・スマートフォンで行えるか、別の言い方で質問する。
- 重さ28kg・3辺合計160cmの荷物について質問する。
- かんぽ生命の診断書が必要になる条件について質問する。

同期状態に加え、ZVAの回答詳細で取得された記事が相談内容に合っていること、本文にある主要な条件や例外が回答から落ちていないことを確認します。新環境の音声実通話、有人転送、AI Expert Assistはそれぞれ実施して確認します。

## 6. 問題が起きたとき

| 症状 | 切り分けと対応 |
| --- | --- |
| 「コンテンツは検出されませんでした」 | 同期ログで原因を確認。以前の銀行KBでは `No start URL configured for crawling` を確認した。一般的な同期失敗すべてが同じ原因ではない。 |
| 開始URLが欠落し、編集画面にも再設定欄がない | リンク探索と開始URLを明示して新規作成する。旧KBは新KBの本文・回答を確認するまで保持し、切替後は参照対象から外す。 |
| 同期成功だが回答できない | 記事本文の有無と、回答詳細で実際に検索された記事を分けて確認。銀行の住所変更は補完2件の関連付けを確認する。 |
| 表や回答本文がない | 言語、ページ選択、抽出設定を確認。必要な個別URLを指定して取り込み直す。 |
| 応答がタイムアウトする | 同期の進行状況と回答詳細を確認。再検索を無制限に繰り返させず、処理が落ち着いてから新しい会話で試す。 |

本書は2026年9月21日の実環境での観測と、2026年9月22日に確認した公開URL・Zoom公式手順に基づきます。記事件数、画面表示、取得結果は新規環境で再確認してください。
