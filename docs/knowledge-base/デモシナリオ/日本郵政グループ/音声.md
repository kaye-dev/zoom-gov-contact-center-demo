# 日本郵政グループ：音声シナリオ

[共通の前提・参照先](README.md)を確認して使用します。引用部分は利用者役の発話例です。AIの返答は定めず、実際の案内を聞いて、まだ確認したい発話だけを続けます。一度に一つの相談を伝え、応答が終わってから話します。

## 1. ゆうちょ銀行の住所変更

引っ越し後、窓口に行かずに登録住所を変更する方法を相談する会話です。

| 順序 | 利用者の発話例 | 進行メモ |
| --- | --- | --- |
| 1 | 「引っ越したので、ゆうちょ銀行に登録している住所を変更したいです。窓口に行かずにできる方法を教えてください」 | 最初の相談。 |
| 2 | 「郵便局に転居届を出せば、銀行の住所も変わりますか？」 | 郵便の手続きとの関係を確認したい場合に追加。 |
| 3 | 「電話で住所を変更することはできますか？」 | まだ電話について聞いていない場合に追加。 |
| 4 | 「郵送で手続きする場合に、注意することはありますか？」 | 郵送について詳しく聞きたい場合に追加。 |
| 5 | 「スマートフォンで手続きする方法も教えてください」 | アプリなどの選択肢を知りたい場合に追加。 |
| 終了 | 「ありがとうございます。案内いただいた方法を確認します」 | 必要な案内を聞けた時点で終了。 |

説明を一度で聞き取れなかった場合は、「今の説明を、要点だけもう一度お願いします」と伝えます。アプリの利用状況などを尋ねられても、事前に決めていない条件は作らず、「まず、利用できる方法の違いを知りたいです」と相談を続けます。

## 2. 郵便物の転居・転送

これから引っ越す人として、旧住所に届く郵便物の扱いと申込方法を相談します。

| 順序 | 利用者の発話例 | 進行メモ |
| --- | --- | --- |
| 1 | 「引っ越しを予定しています。前の住所に届く郵便物を、新しい住所に届けてもらうにはどうすればいいですか？」 | 新しい会話で開始。 |
| 2 | 「郵便局に行かずに申し込む方法はありますか？」 | 申込方法を掘り下げる。 |
| 3 | 「申し込んでから、どのくらいで転送が始まりますか？」 | 申込のタイミングを確認したい場合に追加。 |
| 4 | 「転送してもらえる期間と、費用について教えてください」 | 期間・費用がまだ説明されていなければ追加。 |
| 終了 | 「ありがとうございます。引っ越し前に手続き方法を確認します」 | 申込の実行は行わずに終了。 |

## 3. かんぽ生命の保険金請求書類

個別の契約や病状を伝えず、書類を準備する前の一般的な相談を行います。

| 順序 | 利用者の発話例 | 進行メモ |
| --- | --- | --- |
| 1 | 「かんぽ生命の入院保険金を請求するとき、医師の診断書は必ず必要ですか？ 一般的な条件を知りたいです」 | 新しい会話で開始。 |
| 2 | 「診断書が必要になる条件を、もう少し分かりやすく教えてください」 | 詳しく聞きたい場合に追加。 |
| 3 | 「診断書を使わない場合は、どのような書類を準備するのでしょうか？」 | 書類の選択肢について続ける。 |
| 終了 | 「ありがとうございます。必要な書類を確認してから進めます」 | 個別の支払可否の相談には進まない。 |

契約日や入院内容などを尋ねられた場合は、「手元に契約の資料がないので、今日は一般的な書類の案内をお願いします」と伝えます。

## 任意：ZCCの有人担当へ相談を引き継ぐ

転送先と担当者の待機を確認した場合だけ、上記いずれかの会話の末尾に追加します。

1. 利用者：「この件を担当者に相談したいので、つないでください」
2. 転送操作や接続が進んでいる間は待ちます。接続されない場合は転送を繰り返し要求せず、この場面を終了します。
3. 担当者につながったら、利用者：「先ほど相談した手続きについて、続けて確認したいです」
4. 担当者は、画面で確認できる引継ぎ情報を読み、実際の相談内容に合わせて会話を続けます。必要に応じてAI Expert Assistで記事を確認します。担当者の返答も固定しません。

音声の実通話と転送は、事前リハーサルで確認してから使用してください。
