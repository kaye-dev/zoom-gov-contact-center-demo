# 日本郵政グループ：チャットシナリオ

[共通の前提・参照先](README.md)を確認して使用します。引用部分は利用者役が入力する文章です。AIの返答は定めず、実際の表示内容に応じて、未確認の質問だけを追加します。一つの行を送信したら、回答が終わるまで待ちます。

## 1. ゆうちょ銀行の住所変更

郵便の転居届と銀行の住所変更について、複数の疑問をまとめて相談します。

| 順序 | 利用者の入力例 | 進行メモ |
| --- | --- | --- |
| 1 | 「ゆうちょ銀行の口座の住所変更は、郵便局に転居届を出せば完了しますか。窓口に行かずにできる方法を教えてください。」 | 最初の相談。調整時のチャット検証で使用した質問。 |
| 2 | 「電話だけで住所を変更できますか。郵送ならどの口座でも手続きできますか。」 | 方法や条件を掘り下げたい場合に追加。調整時に使用した追質問。 |
| 3 | 「スマホでできる方法を、サービス名が分かるように整理してください。」 | スマートフォンで進めたい場合に追加。 |
| 4 | 「詳しい手続きを確認できる公式ページがあれば教えてください。」 | 参照先を確認したい場合に追加。 |
| 終了 | 「ありがとうございます。案内を確認してから手続きを進めます。」 | 実際の住所変更は行わずに終了。 |

### 別の言い方で始める場合

新しい会話で、最初の入力を次の文章に置き換えます。これは調整時に確認した言い換えです。

> 引っ越しました。ゆうちょ銀行に登録した住所を自宅から変えたいです。電話か郵送でできますか？スマホでできる方法も知りたいです。

以降は、回答でまだ説明されていないことだけを追加質問します。

## 2. 重い荷物の発送

重さとサイズを具体的に伝え、利用できる発送方法を相談します。

| 順序 | 利用者の入力例 | 進行メモ |
| --- | --- | --- |
| 1 | 「重さ28kg、縦・横・高さの合計160cmの荷物を送りたいです。普通のゆうパックで送れますか。」 | 新しい会話で開始。重さとサイズは固定の例示条件。 |
| 2 | 「この荷物に使える送り方について、普通のゆうパックとの違いを教えてください。」 | 選択肢を詳しく聞きたい場合に追加。商品名を先回りして指定しない。 |
| 3 | 「持ち込める場所と、発送前に確認することを教えてください。」 | 出し方について追加。 |
| 終了 | 「ありがとうございます。発送方法を確認します。」 | 発送受付や集荷依頼の実行は行わずに終了。 |

## 3. かんぽ生命の保険金請求書類

診断書などの必要書類について、一般的な条件と参照先を相談します。

| 順序 | 利用者の入力例 | 進行メモ |
| --- | --- | --- |
| 1 | 「かんぽ生命の入院保険金や手術保険金を請求するとき、医師の診断書が必要になる条件を教えてください。個別の契約ではなく、一般的な案内を知りたいです。」 | 新しい会話で開始。 |
| 2 | 「診断書を使わずに請求する場合、代わりに用意する書類を教えてください。」 | 書類について詳しく聞きたい場合に追加。 |
| 3 | 「必要な書類を確認できる公式ページがあれば教えてください。」 | 参照先を確認したい場合に追加。 |
| 終了 | 「ありがとうございます。契約の資料とあわせて確認します。」 | 契約情報や病歴を入力せずに終了。 |

## 任意：ZCCの有人担当へ相談を引き継ぐ

有人チャットの受信環境と担当者の待機を確認した場合だけ、上記いずれかの会話の末尾に追加します。

1. 利用者：「この件を担当者に相談したいです。有人チャットにつないでください。」
2. 画面に接続操作が表示された場合は、その案内に従います。接続手段が表示されない場合は、接続できたことにせず、この場面を終了します。
3. 担当者につながったら、利用者：「ここまで相談した内容について、続けて確認したいです。」
4. 担当者は、画面で確認できる会話履歴・引継ぎ情報を確認して会話を続けます。AI Expert Assistを使用する場合は、相談内容に関係する記事を確認しながら対応します。担当者の返答も固定しません。

有人接続とAI Expert Assistを含む進行は、事前リハーサルで確認してから使用してください。
