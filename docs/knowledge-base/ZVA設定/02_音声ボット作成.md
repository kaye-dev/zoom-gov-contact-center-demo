# 音声ボット作成

## 参考情報

**コールキューから個人に電話転送する時の挙動転転送する時の挙動**

コールキューから個人に電話転送される時に、`Please press one to accept this call.` のアナウンスがあり、`1` を押下するまでは回線確立しない

```txt
通話が個人の電話番号に転送される場合、通話に接続する前に1を押す必要があります。
このオプションを有効にして、不在着信が個人のボイスメールに行かないようにします。
1を押すのは常に有効で、コールキューの通話で必須です。
```
