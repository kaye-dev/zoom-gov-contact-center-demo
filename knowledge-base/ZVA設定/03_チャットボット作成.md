# チャットボット作成

Zoom Virtual Agent（ZVA）の Chat Agent は一つ作成し、Web サイトからの起動方法と、Zoom Contact Center（ZCC）へ有人転送するかどうかに応じて構成を選びます。

## 構成の選択

| 構成 | 起動方法 | 会話の流れ | Welcome 画面 |
| --- | --- | --- | --- |
| ZVA で完結（有人転送なし） | ZVA Campaign | ZVA Chat Agent で完結 | Campaign で有効・無効を選択 |
| ZCC へ有人転送 | ZCC Campaign | ZCC Web Chat Flow → Bot（ZVA）→ Route To → 担当者 | Campaign で有効・無効を選択 |
| ZCC Flow を直接起動 | Entry ID | ZCC Web Chat Flow → Bot（ZVA）→ Route To → 担当者 | 利用可能。本デモでは最初に表示 |

ZVA から ZCC の担当者へ転送する場合は、ZVA Campaign ではなく、ZVA を組み込んだ Web Chat Flow を ZCC Campaign または Entry ID から起動します。

## 共通：ZVA Chat Agent を作成する

1. `AI Studio` → `Virtual Agents` → `Agents` → `Chat agent`を開きます。
2. Agent guidance、Greeting、対応言語を設定し、ナレッジソースを追加します。一つの Chat Agent に複数言語を設定できます。
3. 必要に応じてスキルを追加し、Preview で回答を確認します。
4. `Publish`をクリックして公開します。

## 1. ZVA Campaign で応対を完結する

1. `AI Studio` → `Virtual Agents` → `Campaigns`で Campaign を作成します。
2. 対象の ZVA Chat Agent、Invitation、Location、`Engagement Window for Web Chat`を設定します。
3. Campaign を公開して Running にします。
4. `Embed Web Tag`から script タグ全体をコピーし、Web サイトへ設定します。

この構成では Contact Center Flow は使用せず、会話は ZVA 内で完結します。

## 2. ZCC Campaign から担当者へ転送する

1. ZVA Chat Agent の設定で`Talk to an agent`トリガーを有効にします。
2. Chat Agent の`Support`に Contact Center のサポートチャネルを追加し、`Channels`から Contact Center へ追加します。
3. ZCC の Web Chat Flow に`Bot`ウィジェットを配置し、公開済みの ZVA Chat Agent を選択します。
4. `Bot`の`Transfer to Staff Service（スタッフ サービスに転送）`出口を`Route To`へ接続し、転送先の Queue または Agent を設定します。
5. Flow を公開し、`Start` → `Manage Entry Point`で Entry ID を割り当てます。
6. `Contact Center Management` → `Campaign Management`で Campaign を作成し、この Flow と Entry Point、Invitation、Location、`Engagement Window for Web Chat`を設定します。
7. Campaign を公開して Running にし、`Embed Web Tag`を Web サイトへ設定します。

`Support`は有人対応の選択肢、`Channels`は Chat Agent の配備先です。本デモでは、有人転送を利用するために両方を設定して確認します。

## 3. Entry ID からZCC Flowを直接起動する

1. 前節と同じ構成の Web Chat Flow を公開し、`Start` → `Manage Entry Point`で Entry ID を割り当てます。
2. `Import SDK`から script タグ全体をコピーし、Web サイトへ設定します。

Entry ID は特定の Flow を直接起動する方式です。ZVA SDK の公式資料では、チャット開始前に利用者情報を収集する Welcome 画面を利用する構成として案内されています。本デモでも最初に Welcome 画面が表示されます。

Welcome 画面の表示は「Contact Center Flow に ZVA を置いたこと」自体によるものではありません。公式資料には Entry ID タグで Welcome 画面を無効にする設定は案内されていません。本デモで有人転送を維持したまま省略する場合は ZCC Campaign 方式を使用し、`Engagement Window for Web Chat` → `Welcome Screen`の`Enable welcome screen`を無効にします。

## Web Tag の違い

```html
<!-- Campaign：data-chat-entry-id なし -->
<script
  type="module"
  src="ZOOM_GENERATED_SDK_URL"
  data-env="ZOOM_ENV"
  data-apikey="ZOOM_API_KEY"
></script>

<!-- Entry ID：data-chat-entry-id あり -->
<script
  type="module"
  src="ZOOM_GENERATED_SDK_URL"
  data-env="ZOOM_ENV"
  data-apikey="ZOOM_API_KEY"
  data-chat-entry-id="ZOOM_CHAT_ENTRY_ID"
></script>
```

SDK URLや各属性を手作業で組み立てず、Zoomの管理画面から発行された script タグ全体を使用してください。
